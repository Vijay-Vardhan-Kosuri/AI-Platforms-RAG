# AI RAG Platform Console

Functional UI for AI Platforms with RAG (Retrieval-Augmented Generation): knowledge bases, documents, embeddings, retrieval, chat, and evaluation.

## Features

- Knowledge base management and indexing status
- Document ingestion and chunk overview
- Embedding model configuration
- Hybrid retrieval, reranking, and citations
- RAG chat with source attribution
- Evaluation metrics: recall@k, MRR, nDCG, hit rate
- Ingestion and retrieval pipelines

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

Open http://localhost:3000
type http://localhost:3002
